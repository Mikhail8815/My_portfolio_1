# 🎨 Сайт-портфолио

Личный сайт-портфолио разработчика, собранный на React с модульной архитектурой и современными практиками.

**[👁️ Посмотреть сайт]myportfolio-ten-amber.vercel.app)** | **[📁 Исходный код](https://github.com/Mikhail8815/My_portfolio_1)**

## О проекте
Минималистичный и производительный лендинг для представления профессионального профиля. Архитектура построена с акцентом на переиспользование компонентов и разделение ответственности.

## 👨‍💻 Реализация
**Frontend-архитектура на React:**
- **Компонентный подход:** Кастомные переиспользуемые компоненты (`/components`)
- **Управление состоянием:** Контекст React для глобального состояния (`/context`)
- **Кастомные хуки:** Логика переиспользования (`/hooks`)
- **Интернационализация:** Поддержка нескольких языков (`/i18n`)

## 🛠 Технологии
- **React** (функциональные компоненты, хуки, контекст)
- **TypeScript** для строгой типизации
- **Styled Components** (подход к стилизации)
- **i18next** для интернационализации

## 📁 Структура проекта (современный подход)
src/
├── components/ # Переиспользуемые UI-компоненты (кнопки, карточки)
├── context/ # React Context для глобального состояния
├── hooks/ # Кастомные React хуки
├── i18n/ # Конфигурация и файлы переводов
├── layout/ # Компоненты макета (хедер, футер)
├── styles/ # Глобальные стили, утилиты, темы
├── assets/ # Изображения, шрифты, иконки
└── App.tsx # Корневой компонент приложения
